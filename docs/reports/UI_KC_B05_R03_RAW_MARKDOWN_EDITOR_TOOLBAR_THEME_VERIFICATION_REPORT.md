## 交付内容

- 编辑态已由 Milkdown 替换为 CodeMirror 6 原始 Markdown 源码编辑器；唯一正文状态为 `bodyMarkdown: string`。

## 架构与兼容性

Milkdown 不能满足“编辑即原始 Markdown、无序列化往返漂移”的约束，因此本次采用 CodeMirror 6。源码转换仅更新编辑器选区，预览和历史/恢复阅读统一走既有安全 Markdown 渲染边界。原始 HTML 仍按既有规则转义；旧颜色标记为兼容读取，不能从新工具栏生成。
